Entry for the [make.fun bounty "One Emoji, One Dream Vacation"](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): a program that writes exactly one emoji to `/output/entry.txt`.

## The entry

🏄 — a surfer catching a wave. One specific dream (a surf trip to a faraway break), not any holiday: the wave and the board land at a glance like a postcard, and the pick stays fresh next to the field's saturated island, Fuji and sunrise angles.

## Run

```sh
node main.ts
```

Writes `entry.txt` (one emoji, no trailing newline) to `$MAKEFUN_OUTPUT_DIR` or `/output`.
